# v2の品質モデルと互換性

## 拡充範囲

10→30 Pack、30→130生成データ種類。既存10 Packには各2種類の新システムを追加し、20の新Packには各4種類を追加しました。各表に100参照行、各Packに100プリセットを同梱します。参照データは手書き完成コンテンツではなく、seed `2762026` から再現できるパラメータ候補です。

`reference_presets.csv` は同じ行番号の候補を集めた選択例です。すべてのIDは実在しますが、経済・難易度が自動で釣り合うことを意味しません。各行は独立プリセットなので、別の表の役割や時系列状態を暗黙に変更しません。

## 型と数値

`catalog/fields.csv` に498フィールドの型、単位、最小・最大、計算式を記載します。既存の公開列名は保持し、曖昧な旧単位は `design_unit` として明示します。新規フィールドは実単位、ゲーム内単位、ratio、multiplierなどを宣言します。実在競技の規格値・実測物理特性を保証するものではありません。

整数境界を持つ列は整数、0/1フラグは真偽値です。確率は0..1、角度は度数法。floatは小数6桁に丸めます。この桁数は測定精度の主張ではありません。

## 役割の違い

`generator/archetype_profiles.py` が全130表の全役割に、1つ以上の明示的な基準値を割り当てます。例: 氷の低グリップ、タレットのジャンプ0、作物ごとの成長日数、海況の波高。基準値の周辺に範囲幅の±6%のseed変動、±4%のTier変動を加え、宣言範囲内に収めます。基準値0はその列の0を保ちます。

その他の値は範囲内のseed成分55%、Tier成分35%、Grade成分10%で生成します。一部戦闘・車両表にはさらに速度/耐久/火力の役割倍率を適用します。Tier/Gradeは設計の選択軸であり、すべての値が強さ順に単調増加する保証はありません。

## 値の依存関係

- 収穫量・部屋面積・レベル域など: min≤max。
- リズム判定: perfect≤great≤good≤miss、得点はgood≤great≤perfect。
- 飛行候補: stall speed≤cruise speed。料理: ingredient cost≤sale price。
- `jump_height_px = jump_speed_px_sec² / (2 × gravity_px_sec2)`。
- `airtime_sec = 2 × jump_speed_px_sec / gravity_px_sec2`。
- `total_frames = startup_frames + active_frames + recovery_frames`。
- `nominal_dps`: damage/interval、STGはさらにprojectile_countを掛ける。
- `ideal_0_to_100_sec = (100 / 3.6) / accel_mps2`。
- `estimated_notes = round(bpm / 60 × duration_sec × notes_per_beat)`。
- 工場出力率、放置の基礎投資回収時間も元の列から計算。

ジャンプ式は一定重力で同じ高さへ着地する理想弾道、DPSは全弾命中する理論値、加速時間は一定加速度の理想値です。衝突・無敵時間・燃費・空気抵抗・アニメーション遷移などは含みません。

## 再現・完全性

生成データはマニフェストにある正規パスだけを読みます。期待する全種類・全shardをsummaryから計算し、各行のID・seedキー・Tier/Gradeを検査し、同じseedから再生成した全列と照合します。ハッシュだけ書き換えた不正値も通りません。

参照CSVはSHA-256・型・式・再生成一致を確認し、3,000プリセットの参照先を検査します。カタログの種類・フィールド一覧とソース定義の一致も検査します。

元のARPGデータには、装備/スキル/クエスト/アイテム/会話/スポーンの参照、複合キー、重み、範囲、XPの連続性、8マップの寸法・タイルID・配置セルの歩行可否・配置間の4近傍到達性検査を追加しました。スポーン半径内すべての地点での安全性やゲーム進行の解法まで保証するものではありません。

## 重複と限界

`quality_report.csv` の多様性署名は役割と元のパラメータ列だけです。ID・seed・Tier・Grade・微小bias・派生列で件数を水増ししません。整数中心の表では候補空間が有限なので重複があり、ユニーク数と重複行数を報告します。全役割の網羅と、少数設定への崩壊は検出します。

新規Packの数値は実測値ではありません。パズルの解、ステージの完成形、リズム譜面のノート配置、演出素材、経済の均衡、対戦公平性を生成・保証しません。

## v1から移行

- 既存の手書きCSV、ID、列は変更しません。追加表は `variants/` にあります。
- 生成器のv1の30データセット名と元の列名は維持しますが、値と分布は変わります。
- 5つの旧データセットには派生列を末尾追加します。列順固定の読み込みはヘッダー名での読み込みへ変更してください。
- 新規出力のsummaryは `generator_version: 2.0.0`。v2検査器はv1生成物を拒否します。
- v1の既存出力を残し、別の出力先でv2を生成してください。破壊的な自動削除は廃止しました。
- 原則リストは `|`。既存ARPGの元素相性だけは従来のカンマ区切りを保って検査します。
